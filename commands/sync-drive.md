# 공유드라이브 동기화

경로는 `PROJECT.md` §3에서 읽는다. 공유드라이브를 쓰지 않는 프로젝트면 그렇다고 말하고 종료한다.

```
로컬 작업 폴더 → 공유드라이브 경로

[1] 파일명 다르지만 같은 문서 → 공유드라이브 쪽 기존 파일명 유지, 내용만 갱신
[2] 파일명 같은 문서          → 덮어쓰기
[3] 실시간 협업 문서(.gsheet 등) → 절대 로컬 파일로 덮어쓰지 않음
[4] 드라이브 전용 폴더(Archive 등) → 건드리지 않음
[5] 스크래치/임시(_scratch/, extract_*.py, 텍스트 덤프) → 동기화 제외
[6] .env 및 민감 파일 → 동기화 제외
[7] 신규 로컬 파일(회의록, 현장 사진) → 신규 복사
```

**이 루틴은 매번 묻지 않고 규칙대로 실행한다.** 규칙에 해당하지 않는 애매한 파일이 생기면 **그때만** 확인을 구한다.

동기화 후 다음을 보고한다:

- 갱신한 파일 / 신규 복사한 파일 / 제외한 파일 (각각 건수와 목록)
- 판단이 애매해 보류한 파일과 그 이유
