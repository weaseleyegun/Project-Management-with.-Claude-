# 주간 루틴

아래를 순서대로 수행한다. 각 단계 결과를 파일에 즉시 반영하고(원칙 1), 반영 위치를 밝힌다.

```
[ ] 1. WBS 진척률 갱신          → wbs-progress (0/25/50/75/100 다섯 단계로만)
[ ] 2. 지연 작업 식별 및 원인 분류 → wbs-progress (귀책 구분, 증빙 필요 여부)
[ ] 3. Task 재정렬               → task-fieldcheck (P0/P1 상단 별도 노출)
[ ] 4. 미결사항 팔로업            → 최근 회의록의 "3. 미결사항" 중 기한 임박·경과 항목
[ ] 5. 리스크 등록부 갱신         → risk-register (현실화된 리스크는 이슈로 전환)
[ ] 6. 주간 보고 메일 초안        → email-draft (B) 구조. 발송은 확인 후
[ ] 7. 공유드라이브 동기화        → /sync-drive
```

## 마지막 출력

- **계획 대비 실적** / **지연 작업과 지연 일수** / **Critical Path 영향** 3가지
- **"지금 결정해야 할 것" 3줄 이내**
