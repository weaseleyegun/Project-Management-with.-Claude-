# 요구사항 관리

## 시트 구성 (엑셀)

```
표지 / 제개정이력 / 도메인별 시트(예: Recipe.AI, Quality.AI, Main.UI) / 공통 / 감리ID_추적표
```

## 요구사항 ID

```
[유형]-[영역]-[일련번호]
FR-VIS-001    기능-비전검사
NFR-PERF-003  비기능-성능
IFR-MES-002   인터페이스-MES연계
DR-PLC-005    데이터-PLC
```

## 필수 항목

| 항목 | 누락 시 |
|---|---|
| ID | 추적 불가 |
| 요구사항명 (명사형 20자 이내) | — |
| 상세 내용 (**검증 가능한 문장**) | 검수 분쟁 |
| 출처 (제안요청서 / 회의일자 / 현장요청) | 범위 근거 상실 |
| 우선순위 (필수/중요/선택) | 축소 협상 불가 |
| **인수 기준** | **최다 분쟁 원인** |
| 관련 산출물 (설계서 章·節) | 추적 단절 |
| 상태 (접수/승인/개발중/검증/완료/보류/제외) | — |

## 작업 지침

1. **모호어를 반드시 지적하고 정량화 대안을 제시한다.**
   - ❌ "실시간으로 빠르게 수집한다"
   - ✅ "설비 태그 1,800점을 1초 주기로 수집, 수집 누락률 1% 이하"
   - 대상 어휘: 등 / 적절히 / 빠르게 / 사용자 친화적 / 최적의 / 안정적으로
2. 인수 기준이 없으면 작성을 거부하지 말고 **초안을 만들어 확인 요청**한다.
3. 신규 요청 판단:
   ```
   기존 요구사항 범위 내인가?
   ├─ YES → 상세화. 하위 항목으로 추가
   └─ NO  → CR 대상. 공수·일정·비용 영향 산정 후 협의 필요 명시
   ```
4. 변경 시 **제개정이력 시트에 버전·일자·변경내용을 즉시 기록**한다(원칙 1).
5. 정부지원사업 등 감리 대응 시 **요구사항 ↔ 산출물 ↔ 화면 추적성 매트릭스**를 별도 유지한다.
6. 검토 결과는 항목 번호 또는 요구사항ID를 매겨 표로 낸다(원칙 3). 이후 "REQ-012" 식 번호 인용 지시가 들어온다.
