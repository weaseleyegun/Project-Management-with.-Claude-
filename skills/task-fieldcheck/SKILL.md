# Task · 현장확인

## Task 포맷

```
- [ ] (P1) [영역] 작업 내용 — @담당 — due: MM-DD — ref: 근거
```

- **P0** 당일 필수(납기·장애·수집중단) / **P1** 금주 / **P2** 차주 / **P3** 백로그
- 작업 내용은 **동사로 종결**한다. "~ 확인"이 아니라 "~ 확인하고 결과를 메일 회신".
- `ref:` 에는 회의일자, 요구사항ID, 메일 제목 등 근거를 남긴다.

## 우선순위 판단 (순서대로)

1. 고객사 납기·검수 일정에 직접 영향 → P0
2. 타인 작업 블로킹 → P0~P1
3. 데이터 수집·운영 중단 → P0
4. 산출물 승인 대기 → P1
5. 개선·최적화 → P2 이하

## 현장확인 질문리스트

- 별도 엑셀(`현장확인_질문리스트.xlsx`)로 관리한다.
- **고객사 실무자가 답변하기 쉽도록 전문용어를 풀어 쉬운 말로 재작성한다.**
  - ❌ "PLC 태그의 스캔 주기와 데드밴드 설정값은?"
  - ✅ "설비 화면의 숫자가 몇 초마다 바뀌나요? 값이 조금만 변할 때도 기록되나요?"

## 작업 지침

1. 대화 중 결정이 나오면 **요청 없이도 Task 후보를 마지막에 정리**한다.
2. 담당자가 불명확하면 `@미정`으로 둔다. 임의 배정 금지.
3. Task가 10개를 넘으면 영역별로 그룹핑하고 P0/P1만 상단에 별도 노출한다.
4. 쪼개기 기준: **한 Task = 한 사람 = 반나절~2일**.
