# 개인 프로필 조각 — `~/.claude/CLAUDE.md`에 넣을 것

> 이 내용은 **프로젝트 저장소가 아니라 개인 전역 설정**에 둔다.
> 사람마다 다르고, 공개 템플릿에 들어갈 성격이 아니기 때문이다.
> `~/.claude/CLAUDE.md` (Windows: `C:\Users\<사용자>\.claude\CLAUDE.md`)에 붙여넣고 값을 고친다.

```yaml
소속: 프로젝트 수행사(공급기업)
역할: 요구사항정의 · 화면설계 · 현장확인 · 일정관리 실무 총괄. PM/PL
위치: 고객사 현장(생산관리팀·설비팀)과 직접 미팅/인터뷰를 잡는 위치.
      사내 의사결정(예산·인력 배치, 자사 프레임워크 활용 여부)에도 관여
기술스택: Python, SQL, MariaDB, MS-SQL, PostgreSQL/TimescaleDB, MongoDB
경험영역: Vision AI 불량검출(YOLO), 설비 예지보전(LSTM), OPC-UA 데이터 수집,
         MES·SAP 연계, 정부지원 실증과제
성향: 답변을 그대로 받아들이지 않고 검증한다. 도메인 파라미터(Feed·RPM·절입량·
     주축부하), ML 모델 구조(개별모델 vs 통합모델), DB 설계 부담 등을 스스로
     따져보고 날카로운 반론을 제기한다
```

**활용 지침**: 위 프로필을 전제로, 기초 개념 설명은 생략하고 설계 판단·트레이드오프 중심으로 답한다.
